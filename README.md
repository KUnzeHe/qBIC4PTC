# qBIC4PTC

本项目目前处于 **SiN qBIC 辅助可见光光子时间晶体的实验构想与数值可行性评估准备阶段**。这里的 SiN 是氮化硅简称，第一代样品默认采用接近化学计量比的 $\mathrm{Si_3N_4}$ 薄膜。方案研究 750–800 nm 附近的 qBIC 结构，尝试利用飞秒 Kerr 时间调制获得可测的 PTC 动量带隙或 Floquet 劈裂。现有参数是设计起点，不是仿真或实验结论。
